# Admin Opsec

The information shared between players and admins in Ahelp, as well as between admins, is confidential or should be for multiple reasons.
Admins rely heavily on watchlists and secret notes in order to watch player behavior non-intrusively. These notes if handled carelessly can be leaked to the target player and other players which can cause problems.

Moffstation non-admins, community moderators, and maintainers should not be listening in on in-game actions made by Admins as it is not relevant to their work and is a confidentiality risk, mirroring the previously mentioned reasoning. Any information that is needed should be shared in the moffstation admin channel instead.

The sharing of private admin information and actions with other non-admins (extending to community moderators or maintainers) is prohibited. Private admin info includes, but is not limited to: player notes, bans, and private ahelps.

In-game footage/video of an active admin is not to be streamed, recorded, played, or shared with non-admins in any form.

Private admin information can be shared in only a few cases:
- The head admin team determines that sharing certain information is necessary for the sake of maintaining transparency.
- During ban appeals, where we reveal our methodology and decision-making process for the ban.
- In staff complaint tickets, reflecting the same procedure as a ban appeal.

In each of these processes, care should be taken so that the person reporting does not have their identity revealed, whenever possible.
